Instrucciones del Dispositivo

1) Conectar alimentación
Conecte el dispositivo a un enchufe eléctrico.
2) Encendido
Encienda el dispositivo usando el switch de baterías y el switch de alimentación.
3) Periféricos y monitor
Conecte HDMI y puertos USB para mouse y teclado.
4) Interfaz inicial
Espere a que aparezca la interfaz.
5) Conexión a Internet
Conéctese a WiFi. Si no hay WiFi, use cable LAN.
6) Abrir Terminal
Abra la terminal (parte superior izquierda).
7) Ruta del proyecto
Ejecute: cd Desktop/EAP
8) Preparación del paciente
Colocar electrodos ECG y dedales PPG siguiendo el manual.
9) Ejecutar programa
Ejecute: python3 eap.py
10) Adquisición
Mantenga medición por al menos 15 segundos.
11) Finalizar
Use botón "Detener" para finalizar.
12) Confirmación
Pulse OK cuando los datos hayan subido correctamente.
13) Nueva medición
Refresque el sitio web para cada nueva toma de datos.
